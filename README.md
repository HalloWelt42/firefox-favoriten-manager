# FavGrid – Premium Speed Dial

Ein eleganter, hochgradig anpassbarer Speed Dial mit Glassmorphism-Design.
Verfügbar für Firefox.

![Version](https://img.shields.io/badge/Firefox-v2.0.0-orange)

---

## Features

- 🎨 **Glassmorphism Design** – Moderne, halbtransparente UI mit Blur-Effekten
- 📂 **Gruppen** – Favoriten in Kategorien organisieren mit Drag & Drop
- 🌙 **Theme-System** – Dark, Light und System-Modus mit 20 Akzentfarben
- 🖼️ **Hintergründe** – Gradienten, Farben oder eigene Bilder (Dark/Light separat)
- 🔍 **Instant-Suche** – Favoriten durchsuchen mit Live-Filterung
- ⌨️ **Tastaturkürzel** – 1-9 für Schnellzugriff, / für Suche
- 🔄 **Import/Export** – JSON, HTML, CSV, OPML, Markdown, URL-Listen
- 🌐 **Intelligentes Favicon-System** – 50+ Quellen mit HTML-Parsing
- 🖼️ **Icon-Bearbeitung** – Weiß entfernen, eigene Bilder, Typ-Badge
- 🌍 **Mehrsprachig** – Deutsch und Englisch (automatisch nach Browsersprache)
- 🔒 **100% Lokal** – Keine Cloud, kein Tracking, keine externen Dienste

## Installation

### Browser-Stores

- **Firefox**: [Mozilla Add-ons](https://addons.mozilla.org/) *(Suche: FavGrid)*


### Manuell (Entwicklermodus)


**Firefox:**
1. `about:debugging#/runtime/this-firefox` öffnen
2. „Temporäres Add-on laden"
3. `manifest.json` aus dem Firefox-Ordner auswählen

## Datenschutz

FavGrid speichert alle Daten ausschließlich lokal in deinem Browser.
Keine Daten werden an externe Server übertragen. Kein Tracking, keine Analyse, keine Werbung.
